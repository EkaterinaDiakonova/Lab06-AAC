Главный вопрос: Почему после запуска программы изменяется использование памяти и во время вычислений увеличивается загрузка процессора?
Ответ: При запуске программа загружается с диска в оперативную память, поэтому потребление RAM растет. Во время вычислений процессор вынужден постоянно считывать данные из памяти и выполнять математические действия, поэтому его загрузка резко увеличивается.
## Итоговый вопрос
Вопрос: Почему нельзя просто сказать: «Процессор запускает программу прямо с HDD/SSD»? Объясните, какую роль здесь играют операционная система и оперативная память.
Ответ: Процессор не умеет напрямую читать данные с диска (HDD/SSD), он работает только с оперативной памятью (RAM). Операционная система находит файл программы на диске, копирует его в RAM и только после этого передает управление процессором на выполнение этого кода.
## Контрольные вопросы
1. Чем файл программы на HDD/SSD отличается от работающего процесса?
Файл - это просто данные, которые лежат на диске и ничего не делают. Процесс - это когда файл загрузили в память, и он начал выполняться.
2. Зачем программе нужна оперативная память после запуска?
Чтобы процессор мог быстро брать оттуда команды и данные для работы. С диска они читаются слишком медленно.
3. Как по Диспетчеру задач можно увидеть, что программа действительно работает?
В Диспетчере появляется новый процесс, у него есть свой PID (номер), и видно, что он занимает память и процессор.
4. Почему во время вычислений увеличивается загрузка CPU?
Потому что процессор выполняет много математических действий подряд (циклы), и на это уходит его вычислительная мощность.
5. Остаётся ли файл программы на HDD/SSD после завершения процесса?
Да, файл остается на диске нетронутым. Исчезает только работающий процесс из оперативной памяти.  
## Итоговый вывод 
Программа хранится на диске (HDD/SSD) в виде файла. Когда мы ее запускаем, операционная система копирует этот файл в оперативную память (RAM), превращая его в работающий процесс. Процессор (CPU) затем берет данные из этого процесса в памяти и выполняет нужные вычисления. После завершения работы процесс исчезает из памяти, но сам файл на диске остается на месте.
